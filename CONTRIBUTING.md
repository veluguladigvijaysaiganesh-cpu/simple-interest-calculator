# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

We appreciate your interest in contributing to this project! This document provides guidelines and steps for contributing.

## How to Contribute

### Reporting Bugs

If you find a bug, please create an issue on GitHub with:
- A clear and descriptive title
- Steps to reproduce the bug
- Expected behavior vs. actual behavior
- Screenshots (if applicable)
- Your environment details (browser, OS, etc.)

### Suggesting Enhancements

We welcome suggestions for new features and improvements. Please create an issue with:
- A clear description of the enhancement
- The motivation or use case for the enhancement
- Any examples or mockups if applicable

### Submitting Bug Fixes

1. Fork the repository
2. Create a new branch for your fix (`git checkout -b bug-fix-description`)
3. Make your changes and test them thoroughly
4. Commit your changes (`git commit -m "Fix: description of the fix"`)
5. Push to your fork (`git push origin bug-fix-description`)
6. Create a Pull Request

### Documentation Improvements

Documentation improvements are always welcome! Follow the same process as submitting bug fixes.

## Code of Conduct

Please note that this project follows a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## Getting Help

If you need help or have questions, feel free to open an issue on GitHub.

Thank you for contributing! 🎉
